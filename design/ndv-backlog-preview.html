Format on save

Run ruff/black on save so stored Python is always tidy; a "Format" button in the editor strip for on-demand cleanup.

Before (as typed)
def run( items ):
  out=[ ]
  for x in items:out.append(x[ "id" ])
  return out
After (formatted)
def run(items):
    out = []
    for x in items:
        out.append(x["id"])
    return out
