Phase A — Code intelligence ✓ shipped

Three features layered onto the shared HighlightedTextarea (the inline node-code editor and the Expand modal both get them). All gated to language="python", so expression fields are untouched.

A1 · active line + A2 · autocomplete

Caret context as you type

The current line gets a subtle accent band + a brightened gutter number. Type an identifier and a caret-anchored completion popover appears — keywords, builtins, the code-node API (inputs / context / items) and names already in the buffer. ↑↓ move, Tab accept, Esc close.

def transform(inputs): rows = inputs["main"] ret # map each row return rows

  • repr builtin
  • reversed builtin
Band sits above the syntax mirror but below the caret layer, so colours stay visible.
A3 · lint

Ruff diagnostics, inline

Debounced lint runs through ruff check on the backend (never executes code). Offending lines get a coloured gutter dot; a strip below lists every finding — click to jump. Falls back to an AST syntax check if ruff isn't available.

12345
import os def run(inputs): total = 0 return amount # unreachable
  • 1:8F401`os` imported but unused
  • 4:12F821undefined name `amount`
Amber = warning, red = error. Worst severity wins per line in the gutter.
