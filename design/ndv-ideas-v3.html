Idea 3

Reset-to-default on hover

A subtle ↺ button appears on any field that differs from its node default. One click restores it — no guessing what the original value was.

Idea 4

Output diff vs previous run

When a node has run before, the Output panel can show what changed since the last run — added / removed / modified keys highlighted. Great for debugging flaky transforms.

Idea 5

Pin sample input

Pin a node's current input so you can iterate on parameters without re-running the whole upstream chain. A 📌 badge marks pinned data; one click to refresh or unpin.

📌 Pinned input Refresh Unpin
Edits to params re-evaluate against the pinned data instantly — no upstream re-run.
Idea 6

Inline error → AI fix

When a node errors, surface the message inside the NDV with a one-click “Explain” / “Fix with AI” action that patches the offending parameter or code in place.

⚠ KeyError: 'amount' — field not found in input
✦ Fix with AI Explain
