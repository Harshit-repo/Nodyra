Workflow cards

Inspector header tints to the selected node's category color. Tab underlines and input focus rings follow. The tool feels alive — not a generic sidebar.

Run Timeline drawer
Gantt-style execution view replacing raw port data. Shows node durations, parallel execution, total wall-clock time. Click bar → opens that node in NDV.

Credential health badges
Verified / Expiring / Invalid pills on each credential. Shows last-tested time. Catches revoked tokens before a workflow breaks at runtime.
