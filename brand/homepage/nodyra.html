import psycopg2, requests, pandas as pd
from nodyra import workflow, node

@node(trigger="webhook", path="/signups")
def webhook_trigger(event):
    return {"payload": event.json()}

@node
def fetch_data(inputs):
    conn = psycopg2.connect(env["POSTGRES_URL"])
    df = pd.read_sql("SELECT * FROM signups WHERE created_at > NOW() - INTERVAL '24h'", conn)
    return {"data": df}

@node
def transform(inputs):
    df = inputs["data"]
    result = df[df["status"] == "active"]
    return {"filtered": result, "count": len(result)}

@node
def http_request(inputs):
    requests.post(env["SLACK_WEBHOOK"],
        json={"text": f"{inputs['count']} new signups today"})
    return {"sent": True}

workflow.run(webhook_trigger >> fetch_data >> transform >> http_request)

A Deployment attaches a schedule to a published workflow version. It fires on a cron expression or a simple interval, injects default parameters, and can hand off to an error workflow on failure.

Full cron syntax with IANA timezone
Write any valid cron expression (0 9 * * 1-5) or use a simple interval. Timezone evaluated using the IANA tz database — Australia/Sydney, not a UTC offset.
Pin to a workflow version
Pin a Deployment to a specific published version, or always run the latest. Override the environment and runner pool per deployment without touching the workflow.
Error workflow on failure
Route any failed run to a separate error-handling workflow. Configure alert policies — know within seconds if something breaks.

Enterprise

Enterprise-grade controls — baked in, not bolted on.

RBAC, encrypted credential vault, SSO, and immutable audit logs ship with every installation. No separate security add-on required.

SAML 2.0 & OIDC — Okta, Google Workspace, Azure AD
Air-gap friendly — license verified offline, no phone-home
Append-only audit log — exported as NDJSON

Role-Based Access Control

Four roles — Owner, Admin, Editor, Viewer — enforced at workflow, environment, and credential level.

Encrypted Credential Vault

Envelope encryption throughout: every credential gets its own data key, wrapped by a per-organisation key, wrapped by a master key derived with HKDF-SHA256. Bring your own KMS — HashiCorp Vault, AWS KMS or GCP KMS — and the master key never touches Nodyra's storage at all.

SSO & OIDC

SAML 2.0 and OIDC support out of the box. Integrates with Okta, Azure AD, Google Workspace, and any compliant IdP.

Append-Only Audit Log

Every run, edit, and access event recorded with actor, timestamp and delta. Nothing in the product updates an audit row. Stream the whole log out as NDJSON from a single endpoint and pipe it into Splunk, Datadog or object storage; a retention window you set is the only thing that ever removes an entry.

Cron Triggers & Retry Policy

Schedule any workflow with a cron expression. Configure retry policies — max attempts, delay, exponential backoff, dead-letter queue.

Workflow Versioning

Every save creates a versioned snapshot. Compare diffs between versions, roll back in one click, or branch a workflow for experimentation.

Unsafe-Node Policy

Nodes that touch the filesystem, network, or subprocesses are flagged at publish time. Your policy decides: warn, require approval, or block activation outright.

Credential Testing

Test every connection before you run anything. Per-type test handlers verify API keys, OAuth tokens, and database credentials, and report exactly why a connection fails.

Multi-Tenancy

Run isolated organisations on one installation with row-level separation across workflows, credentials, environments, and audit events — sandboxing enforced automatically.
