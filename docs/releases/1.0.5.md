and follow the [single-host installation guide](../deployment/self-hosted.md).

## What changed

This release includes the self-hosting and security fixes from 1.0.3/1.0.4,
the updated product homepage, and a recorded workflow tour. It fixes crowded
node data headers so timing, item counts, and view controls remain readable.
See the [changelog](../../CHANGELOG.md) for the complete release history.

## Distribution limits

- Source archives are supplied for local Docker builds. Signed prebuilt 1.0.5
  images and image attestations are not included.
- GitHub Actions jobs could not start because of the account billing block;
  the checks above were run locally. No hosted 1.0.5 CI success is claimed.
- The supported beta profile is one host with trusted workflow authors. It
  does not establish high availability or isolation between hostile tenants.
- HTTPS checks used a temporary test certificate. Operators configure their
  own domain, trusted certificate, secrets, and backups.

## Upgrades and backups

Keep deployment secrets and persistent volumes. Read the
[backup and restore guide](../backup-restore.md) before updating an existing
installation, and test restoration before depending on a backup. Fresh-install
and restart verification do not establish every possible upgrade path.
